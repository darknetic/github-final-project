# Simple Interest Calculator

## Project Description
This project contains a Bash script that calculates simple interest using the principal amount, annual rate of interest, and time period entered by the user.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Features
- Accepts the principal amount as input.
- Accepts the annual interest rate as input.
- Accepts the time period in years as input.
- Calculates and displays simple interest.
- Displays the total amount, including interest.

## Usage
Run `simple-interest.sh` in a Bash-compatible terminal with `awk` installed, then enter the requested values.
